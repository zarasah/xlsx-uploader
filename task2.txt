Уточняющие вопросы для менеджера:

1. Формат данных Excel:
   - Какую конкретную структуру Excel-файла нужно ожидать (например, количество и порядок столбцов)?

3. Валидация данных:
   - Какие конкретные правила для валидации дат? Например, допустим ли формат даты в стиле "d.m.Y" или нужно ожидать формат "Y-m-d"?
   - Что делать с повторяющимися данными (например, строки с одинаковым `id`)?

4. Сохранение данных:
   - Как обрабатывать ошибки при сохранении данных в базу данных? Например, что делать, если строка не может быть сохранена ?

5. Прогресс импорта в Redis:
   - Как будет происходить обновление прогресса в Redis — с использованием таймера или при каждом импорте строки?

6. WebSocket:
   - Какие данные должны передаваться в событии WebSocket? Например, должно ли событие содержать только строку или информацию об импорте в целом?

7. API для группировки данных:
   - Как должно выглядеть API для предоставления данных? Требуется ли поддержка пагинации или просто возвращение всех данных по группе?

Задача для джуниора:

1. Загрузить Excel файл:
   - Создать форму для загрузки Excel файла.
   - Использовать библиотеку для парсинга Excel файла.

2. Валидация данных:
   - Для каждой строки проверить данные на наличие ошибок. Проверить:
     - Пустые поля.
     - Неверный формат даты.
     - Повторяющиеся `id`.
   - Если строка прошла валидацию, сохранить её в базе данных. Если нет, пропустить её, записав ошибку в отчёт.

3. Прогресс импорта:
   - Каждую строку, которую обработает программа, считать как прогресс.
   - Сохранять прогресс в Redis. Для этого использовать уникальный ключ.

4. Передача событий через WebSocket:
   - После того как строка будет сохранена, отправить событие всем подключённым клиентам через WebSocket.

5. Группировка данных по дате через API:
   - Создать API, которое будет возвращать данные, сгруппированные по дате.

6. Отчёт об ошибках:
   - В конце импорта создать текстовый файл с ошибками валидации для каждой строки. Отчёт должен содержать:
     - Номер строки.
     - Описание ошибки.
